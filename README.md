## Install

**Windows** — grab `quartz-setup-<version>.exe` from the
[releases](https://github.com/Someone68/quartz/releases). The installer is not
code-signed, so SmartScreen will say "Windows protected your PC": click
**More info** → **Run anyway**. It installs per-user (no admin prompt) and can
start the background service at login.

**Linux** — `.deb` and `.rpm` from the same releases page, or
`make from-source` for a user-scoped install on any distro.
